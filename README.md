# Inspect Ranges

Welcome to Inspect Ranges, an extension for [Inspect AI](https://inspect.aisi.org.uk).

Learn more about using Inspect Ranges at <https://meridianlabs-ai.github.io/inspect_ranges>.

## Development

To work on development of Inspect Ranges, clone the repository and `uv sync`:

```bash
git clone https://github.com/meridianlabs-ai/inspect_ranges
cd inspect_ranges
uv sync
```

Run linting, formatting, and tests via

```bash
make check
make test
```
